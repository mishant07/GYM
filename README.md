# Twenty (Gym preview)

This is a static preview of the "Twenty" gym booking UI (single-file app). To deploy this site, upload the contents of this folder to any static hosting provider.

Quick deployment options

- GitHub Pages (repo `main` branch):

  1. Create a new GitHub repository and push this folder.
  2. In repository Settings → Pages, set the source to `main` branch and root (`/`).
  3. Wait a minute and visit `https://<your-username>.github.io/<repo-name>/`.

- Netlify (drag & drop or connect repo):

  1. Go to https://app.netlify.com/sites/new
  2. Drag-and-drop this folder or connect your GitHub repo.
  3. Netlify will publish and provide a free URL.

- Vercel:

  1. Go to https://vercel.com/new and import the repository.
  2. Use default settings (framework: Other / static).
  3. Vercel will deploy and provide a URL.

Local test

- Open `index.html` in a browser to preview locally.
